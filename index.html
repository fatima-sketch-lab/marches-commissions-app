CAS A : Consensus Total

Tous les membres votent Favorable avant l'échéance → Aucune réunion. Le PV officiel certifié est généré et signé électroniquement immédiatement.

CAS B : Réserves Mineures

Un médecin émet une réserve technique (ex: SAV, connectique) → Le fournisseur répond par écrit sur la plateforme sous 48h. Si levée, PV validé sans réunion.

CAS C : Désaccord ou Avis Défavorable

Avis défavorable motivé → L'application calcule immédiatement le créneau optimal où le quorum est disponible et programme une micro-réunion ciblée de 20 min sur le point bloquant.
